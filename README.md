# Notion
Notion — это полнофункциональное веб-приложение для управления персональными задачами, построенное на современном стеке технологий. Приложение позволяет пользователям регистрироваться, входить в систему, создавать задачи, отмечать их как выполненные, редактировать и удалять. Каждый пользователь видит только свои задачи — полная изоляция данных между аккаунтами.

Ссылка на веб-приложение - https://notion-tau-drab.vercel.app/
Ссылка на API - https://notion-production-d07a.up.railway.app/docs

## Предварительные требования:
+ Установленный Docker и Docker Compose
+ 1 ГБ свободной памяти
+ Порты 3000, 8000, 5432 должны быть свободны

## 🚀 Как запустить проект

+ Клонируйте репозиторий и перейдите в папку проекта
```
git clone https://github.com/GGGamzat/Notion.git
cd Notion
```

+ Запустите все сервисы одной командой
```
docker-compose up --build
```

### После запуска проверьте:
+ Frontend доступен по: http://localhost:3000
+ Backend API доступен по: http://localhost:8000
+ Swagger документация: http://localhost:8000/docs

### Коммуникация между сервисами
Пользователь → Frontend (:3000) → Backend (:8000) → Database (:5432)

## Основной функционал

### Аутентификация и авторизация
+ Регистрация нового пользователя
+ Вход в систему с email и паролем
+ JWT токены для защиты API

### Управление задачами (CRUD)
+ Создание задач с заголовком и описанием
+ Просмотр списка задач
+ Редактирование существующих задач
+ Отметка задач как выполненных
+ Удаление задач

### Пользовательский интерфейс
+ Адаптивный дизайн (работает на мобильных и десктоп)
+ Интуитивное управление
+ Валидация форм
+ Сообщения об ошибках

## API Endpoints
+ POST   /users/register  - Регистрация пользователя
+ POST   /users/login     - Вход в систему (получение токена)
+ GET    /tasks/          - Получить список задач
+ GET    /tasks/{id}      - Получить конкретную задачу
+ POST   /tasks/          - Создать новую задачу
+ PUT    /tasks/{id}      - Обновить задачу
+ DELETE /tasks/{id}      - Удалить задачу
+ PATCH  /tasks/{id}/completed - Переключить статус выполнения
